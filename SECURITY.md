# Security Policy

## Supported versions

Only the latest major release line of `@d1g1tal/watchr` receives security fixes.

| Version | Supported |
|---|---|
| latest major | Yes |
| older majors | No |

## Reporting a vulnerability

Please do **not** open a public issue for security problems.

Use GitHub's private vulnerability reporting for this repository:
**Security → Report a vulnerability** (https://github.com/D1g1talEntr0py/watchr/security/advisories/new).

Include the watchr version, Node.js version, operating system/filesystem, and a minimal reproduction if possible.
You will receive an acknowledgement, and a fix or mitigation will be coordinated through a GitHub Security Advisory
before public disclosure.
